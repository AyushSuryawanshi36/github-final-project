# Simple Interest Calculator

## Project Name
**Simple Interest Calculator**

## Description
A simple Bash script to calculate simple interest based on user input.

Simple interest is calculated using the formula:

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Features
- Accepts user input for principal amount, rate of interest, and time period
- Calculates and displays the simple interest
- Easy to use command-line interface

## Usage
Run the script and provide the required inputs when prompted:

```bash
bash simple-interest.sh
```

## Inputs
- **Principal**: The initial amount of money
- **Rate of Interest**: The annual interest rate (in %)
- **Time Period**: The duration (in years)

## Output
The script outputs the calculated simple interest.
